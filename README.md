# 🐼 熊猫资讯 PandaDaily

圈养大熊猫垂直资讯科普公益站（粉丝公益资讯站），纯原生 HTML + CSS + JavaScript 静态站，零框架、零构建、零外部图片依赖，部署即用。

## ✨ 功能

- **首页**：今日主角 > 大事件快讯 > 最新科普 > 场馆动态 > 精选投稿，六大板块入口
- **全球熊猫馆动态**：国内/海外双标签、关键词搜索、场馆关注、单场馆专题页（熊猫名单 + 动态 + 官网入口）
- **熊猫圈大事件**：按年时间线、6 类标签、置顶快讯，每条标注【官方实锤】/【网传待证实】
- **熊猫文创专栏**：官方上新 / 限量 / 绝版 / 正版测评 / 盗版避雷，仅展示不交易，独立避雷专区
- **猫粉投稿 UGC 社区**：实拍 / 游记 / 科普 / 手绘四类投稿、月度精选、点赞评论（评论需审核）
- **今日主角**（核心王牌）：每日 0 点自动切换（日期哈希轮换），成长大事记 / 名场面 / 图库 / 关联科普，随机档案
- **熊猫科普专栏**：六大分类 + 难度分级，独立辟谣专题，粉丝提问入口
- **熊猫档案库**：谱系号 / 姓名 / 场馆检索、随机档案、详情上下只切换
- **投稿提交**：强制勾选版权授权 + 非商用展示协议，后台人工审核
- **关于我们**：完整合规免责声明（非官方、以官方为准、无广告无交易）

## 🛠️ 后台 CMS

入口 `admin.html`，默认密码 `panda2024`（后台可修改）：

- 内容管理：科普 / 大事件 / 文创 CRUD + 置顶
- 投稿审核：通过 / 驳回（备注）/ 拉黑 / 月度精选
- 评论审核
- 熊猫档案库 CRUD（含大事记 / 趣闻 JSON 编辑）
- 场馆管理（含动态 JSON 编辑）
- 今日主角：自动轮换 / 手动指定 / 轮换名单
- 站点设置：站名、公告、管理密码、数据导出 / 重置

## 🚀 部署

纯静态站，任意静态托管即可（CloudStudio / GitHub Pages / Vercel / Nginx...）：

```bash
# 本地预览
python -m http.server 3000
# 或
npx serve .
```
